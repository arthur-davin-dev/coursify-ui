# Coursify 🎓

**Empowering the Next Generation of Learners in Cambodia**

Coursify is a modern e-learning platform specialized in programming, web development, and IT skills. Built with a "Mobile-First" philosophy and full localized support, Coursify provides a premium, high-performance educational experience.

🔗 **Live Demo:** [https://cousify.vercel.app/](https://cousify.vercel.app/)
📂 **GitHub Repo:** [https://github.com/Y2S1-2025-2026/e-learning-frontend.git](https://github.com/Y2S1-2025-2026/e-learning-frontend.git)

🔗 **Live Demo:** [https://admin-coursify.vercel.app/](https://admin-coursify.vercel.app/)
📂 **GitHub Repo For Admin:** [https://github.com/Arthurdavin/Admin-Coursify.git](https://github.com/Arthurdavin/Admin-Coursify.git)

## ✨ Key Features

- **Responsive Design**: Intelligent image handling for team and hero sections, ensuring no "parts are missed" on mobile.
- **Multilingual Support**: Fully integrated i18n for English and Khmer.
- **Advanced Typography**: Optimized rendering for Khmer Unicode using specialized Google Fonts:
  - `Moul` (Headings)
  - `Odor Mean Chey` (Stylized text)
  - `Kantumruy Pro` (Body text)
- **SEO Ready**: Comprehensive metadata, OpenGraph tags, and Twitter cards for professional social sharing.
- **State Management**: Robust data flow using Redux/Toolkit via a custom `StoreProvider`.
- **Premium UI**: Dark mode support with glassmorphism effects and Framer Motion animations.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14+](https://nextjs.org/) (App Router)
- **Language**: TypeScript / JavaScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **State Management**: Redux Toolkit
- **Notifications**: [Sonner](https://sonner.emilkowal.ski/)

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Y2S1-2025-2026/e-learning-frontend.git
   cd e-learning-frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run Development Mode**
   ```bash
   npm run dev
   ```

## 📐 Project Structure (Root Level)

This project uses the root-level directory structure (no `/src` folder):

```text
/app          # Next.js App Router (Layouts, Pages, APIs)
/components   # UI components (Hero, Navbar, Footer)
/store        # Redux slices and StoreProvider
/locales      # i18n translation files (en/km)
/styles       # Tailwind & Global CSS
/public       # Static assets (Hero images, favicon, thumbnails)
```
